# 寻页完整使用手册

## 1. 第一次运行

在 Windows 文件资源管理器中进入 `E:\大二\鼎甲杯\xunye`，双击 `start.bat`。控制台出现“寻页 XUNYE 已启动”即表示成功。

如果没有安装 Node.js，先从 <https://nodejs.org/> 安装 LTS 版本。安装完成后关闭旧终端，重新打开再启动。

手机端入口：<http://localhost:3000>  
管理端入口：<http://localhost:3000/admin>

服务第一次启动时会自动创建 `data/xunye.db`。这是平台全部业务数据，删除它会重置演示数据，所以正式使用后不要随意删除。

## 2. 读者演示路径

### 登录

1. 手机端右上角点击“登录”，或进入“我的”。
2. 可使用账号 `reader`、密码 `123456`。
3. 也可点击演示账号区域的“读者”一键登录。
4. 新用户可以自己注册，注册后自动获得 10 元阅读余额。

### 找书

- 首页搜索框可以搜索书名、作者和简介关键词。
- 首页分类入口会自动进入书城并带上分类筛选。
- 书城可继续切换“热度、新上架、最近更新、评分”排序。
- 点击封面进入作品详情。

### 阅读

1. 作品详情中点击“开始阅读”或“继续阅读”。
2. 免费章节直接打开。
3. 目录中带锁图标的章节需要购买或会员权益。
4. 阅读页底部可切换上一章/下一章。
5. 点击“阅读设置”：
   - 字号：16–26px。
   - 字体：宋体/黑体。
   - 背景：深夜、纸张、青竹、雾蓝、旧玫。
   - 文字颜色、背景颜色：可选任意自定义颜色。
   - 行距：1.6–2.3。
   - 模式：滚动/分页。
6. 雾蓝和旧玫是会员专属主题。普通用户点击会收到会员权益提示。
7. 离开章节后，已登录用户的进度会自动保存。

### 收藏与书架

1. 作品详情点击“收藏”，书会进入“我的 → 我的书架”。
2. 书架显示最后阅读章节和阅读百分比。
3. 再次点击收藏可取消。

### 购章

1. 在目录点击付费章节。
2. 弹窗显示当前购章价格和余额。
3. 点击“使用阅读余额购买”。
4. 购买成功后自动进入阅读，购买记录永久保存。
5. 余额不足时进入“我的 → 余额充值”。

### 会员

1. 进入“我的 → 会员中心”，或点击首页的会员卡片。
2. 选择月卡、季卡或年卡。
3. 当前演示版为模拟支付，点击后立即开通。
4. 会员权益会实时显示在“我的”页面。
5. 会员续费时，有效期会从当前到期日继续累加，而不是从今天重新计算。

会员权益包含：

- 会员书库标识。
- 标记为“会员免费”的章节。
- 购买普通付费章节时按套餐折扣付款。
- 会员专属阅读主题。
- 头像和评论区 VIP 标识。
- 平台不展示商业广告。

### 充值与打赏

- 充值到账的是阅读余额，不与会员有效期混用。
- 充值档位可以在 Web 端修改，手机端刷新后同步。
- 作品详情点击打赏图标，选择 1、3、5、10 元或输入自定义金额。
- 打赏从阅读余额扣除，作者获得 70%，平台保留 30%。
- 所有余额变化都能在“我的 → 订单与流水”查看。

### 评论

1. 作品详情切换到“书评”。
2. 输入不超过 500 字的内容并发布。
3. 管理员可以在 Web 端隐藏违规评论。
4. 作者和 VIP 用户的身份标签会显示在昵称旁。

### 论坛

1. 底部导航进入“社区”。
2. 可以按“找书、讨论、作者”筛选。
3. 点击“发帖”，选择类型并提交。
4. 新帖子进入 `pending` 审核状态，不会立即公开。
5. 管理员审核通过后，其他读者能看到并回复。

## 3. 作者演示路径

1. 使用 `author`、密码 `123456` 登录。
2. 底部导航点击“创作”。
3. 工作台显示作品数、累计阅读、收藏数和打赏分成。
4. 点击“新作品”，填写书名、分类、简介。
5. 作品创建后点击“新建章节”：
   - 填写章节标题和正文。
   - 价格填 0 表示免费；填 0.30 表示 0.30 元。
   - 可设置会员免费。
   - “保存草稿”不会公开。
   - “提交审核”会进入管理员审核队列。
6. 作品审核通过后进入手机书城。
7. 管理端驳回时填写的意见会显示在作者作品卡片中。
8. 作者打赏收入显示在指标卡和余额流水中。

普通读者要成为作者：

1. 登录后点击“创作”。
2. 点击“申请成为作者”。
3. 身份会立即更新，随后可以创建作品。

## 4. 管理员演示路径

使用 `admin`、密码 `123456` 登录 <http://localhost:3000/admin>。

### 内容审核

1. 左侧点击“内容审核”。
2. 三列分别显示待审作品、待审章节和待审论坛帖子。
3. 点击“通过”后内容立即对读者可见。
4. 点击“驳回”时需要填写审核意见。
5. 作者在手机端可以看到该意见。

### 查看全部内容

- “作品与章节”页显示所有状态，而不只是待审核内容。
- 顶部搜索框支持书名、章节名、作者名搜索。
- 可核对价格、字数、会员权益、阅读量和发布状态。

### 用户与评论

- 用户表显示用户名、邮箱、角色、余额、会员到期时间和账号状态。
- 点击“停用”会立即删除该用户全部登录会话，之后无法登录。
- 点击“恢复”可重新启用账号。
- 评论表可以隐藏或恢复评论。

### 平台配置

“平台配置”分四块：

1. 内容分类：名称、单字图标、主题色和启用状态。
2. 会员套餐：名称、有效天数、售价、原价、购书折扣、权益文案、推荐和排序。
3. 充值档位：支付金额、基础到账、赠送、推荐和排序。
4. 平台公告：标题、正文和类型。手机端首页读取最新公告。

配置保存后直接写入数据库，手机端下次请求首页或钱包时同步最新内容。

### 订单与打赏

- 订单页显示充值订单和会员订单。
- 打赏表显示读者、作品、作者、打赏金额、作者 70% 分成和留言。
- 运营总览中可查看近七日收入柱状图与分类内容分布。

## 5. 数据保存与恢复

- 数据库位置：`data/xunye.db`。
- 备份：在服务停止时复制整个 `data` 目录。
- 恢复：停止服务，用备份的 `xunye.db` 覆盖当前文件，再启动。
- 重置演示数据：停止服务后删除 `data/xunye.db`，下次启动会重新生成全部演示内容。

## 6. 常见问题

### 页面提示“寻页暂时无法连接”

确认运行 `start.bat` 的窗口没有关闭，并检查 <http://localhost:3000/api/health> 是否返回 `status: ok`。

### 手机打不开电脑地址

- 检查两台设备是否在同一 Wi-Fi。
- 使用电脑局域网 IPv4，而不是 `127.0.0.1`。
- Windows 防火墙允许 Node.js 的“专用网络”访问。
- 某些校园网会隔离设备，此时可用手机热点或部署到云端。

### 忘记管理员密码

演示环境可以删除 `data/xunye.db` 重置。正式环境不要删除数据库，应通过数据库脚本或后台重置流程修改密码。

### 为什么手机不能安装 PWA

Service Worker 要求 HTTPS。局域网 HTTP 可以正常操作和阅读，但“安装应用”可能不可用。使用 HTTPS 域名或隧道地址即可。

### 充值后为什么余额没变

检查是否点击的是“会员中心”而不是“余额充值”。会员订阅不会增加余额，这是刻意的资产隔离设计。
